# Medisiner og medikamenter

Som lærling har du **ikke selvstendig adgang** til å ta ut eller dele ut medisiner når dette krever høyere grad.

## Hvem kan håndtere medisiner?

Etter Auralia Universitetssykehus sine interne RP-regler skal medisiner håndteres av personell med **Paramedic-grad eller høyere**.

Dette omfatter blant annet:

* Tabletter og paracetamol
* Kvalmestillende midler
* Intravenøs behandling (IV)
* Ringer-løsning

## Hva gjør du som lærling?

Dersom du mener medisiner eller behandlingsutstyr er nødvendig, kontakt tilgjengelig personell med riktig grad og følg instruksjonene deres. **Ikke improviser eller utfør behandling du ikke er godkjent for.**

{% hint style="danger" %}
Dette er fiktive rutiner for FiveM RP og skal ikke brukes som medisinsk veiledning i virkeligheten.
{% endhint %}
