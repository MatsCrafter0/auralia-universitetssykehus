# Pasientprioritering og alvorlige hendelser

Ved flere skadde skal personellet først vurdere **egensikkerhet**, skaffe oversikt og varsle ILH om ressursbehov.

* **Rød:** Kritisk, livstruende tilstand.
* **Gul:** Alvorlig skade som haster, men foreløpig stabil.
* **Grønn:** Mindre alvorlig skade.

Prioriteringen vurderes på nytt hvis pasientens tilstand endres. Ved skyting, vold eller andre utrygge områder avventer helsepersonell politiets sikring.

**Serverens LPS-huskeregel:** X = Egensikkerhet, A = Airway, B = Breathing, C = Circulation, D = Disability, E = Exposure. Dette er serverens RP-oppsett. Bruk `/meg` for relevante RP-handlinger.
