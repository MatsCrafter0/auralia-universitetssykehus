* Kontroller hvilke [tjenestekrav](https://auralia-universitetssykehus.gitbook.io/auralia-universitetssykehus-docs/bFQZOUHYM4q2rhjvjWcV/ansatte-og-graderinger/forerkort-og-tjenestekrav), [uniformregler](https://auralia-universitetssykehus.gitbook.io/auralia-universitetssykehus-docs/bFQZOUHYM4q2rhjvjWcV/ansatte-og-graderinger/uniform-og-bekledning) og [krav til tjenesteutstyr](https://auralia-universitetssykehus.gitbook.io/auralia-universitetssykehus-docs/bFQZOUHYM4q2rhjvjWcV/operativ-tjeneste/tjenesteutstyr) som gjelder.

* Bruk **T–T–T (Tenk – Trykk – Tal)** og **K–K (Kort og konkret)** på samband.

* Oppkall om **OPS (orden på stedet)** og retur med pasient skal gå gjennom 01.

Se [Radio og samband](https://auralia-universitetssykehus.gitbook.io/auralia-universitetssykehus-docs/bFQZOUHYM4q2rhjvjWcV/operativ-tjeneste/radio-og-samband).

## Ved et skadested

1. **Egensikkerhet først.** Vurder situasjonen før du går inn.
2. Ved vold, skyting eller utrygge forhold: **avvent politiets sikring**.
3. Skaff oversikt og meld ressursbehov.
4. Ved flere skadde: varsle **ILH** og prioriter pasienter.
5. Gjennomfør relevant RP-behandling og la andre spillere bidra til scenen.

**Prioritering:** 🔴 Rød = kritisk/livstruende · 🟡 Gul = alvorlig, foreløpig stabil · 🟢 Grønn = mindre alvorlig.

**LPS:** X = Egensikkerhet · A = Airway · B = Breathing · C = Circulation · D = Disability · E = Exposure.

Les [Pasientprioritering og alvorlige hendelser](https://auralia-universitetssykehus.gitbook.io/auralia-universitetssykehus-docs/bFQZOUHYM4q2rhjvjWcV/pasientbehandling/pasientprioritering-og-alvorlige-hendelser), [Innsatsleder Helse](https://auralia-universitetssykehus.gitbook.io/auralia-universitetssykehus-docs/bFQZOUHYM4q2rhjvjWcV/operativ-tjeneste/innsatsleder-helse-ilh) og [Masseskadehendelser](https://auralia-universitetssykehus.gitbook.io/auralia-universitetssykehus-docs/bFQZOUHYM4q2rhjvjWcV/beredskap/masseskadehendelser).

## Samarbeid og krevende pasienter

* Politiet håndterer trusler, vold og sikring av utrygge områder.
* Helsepersonell overtar ikke politioppgaver.
* Møt aggressive pasienter rolig. Hold avstand og trekk deg tilbake ved fare.

Se [Samarbeid med nødetater](https://auralia-universitetssykehus.gitbook.io/auralia-universitetssykehus-docs/bFQZOUHYM4q2rhjvjWcV/operativ-tjeneste/samarbeid-med-nodetater) og [Aggressive pasienter](https://auralia-universitetssykehus.gitbook.io/auralia-universitetssykehus-docs/bFQZOUHYM4q2rhjvjWcV/pasientbehandling/aggressive-pasienter).

## [Beredskap](https://auralia-universitetssykehus.gitbook.io/auralia-universitetssykehus-docs/bFQZOUHYM4q2rhjvjWcV/beredskap)snivåer

| Nivå     | Betydning                                        |
| -------- | ------------------------------------------------ |
| 🟢 Grønt | Normal drift                                     |
| 🟡 Gult  | Økt oppmerksomhet og ekstra ressurser            |
| 🔴 Rødt  | Full mobilisering og skjerpede sikkerhetsrutiner |

**Gult:** Ambulanser parkert ute skal være låst når de ikke er i bruk. Makker er sterkt anbefalt.

**Rødt:** Strengere bemannings- og kjøretøyregler gjelder. Les [Rødt farenivå](https://auralia-universitetssykehus.gitbook.io/auralia-universitetssykehus-docs/bFQZOUHYM4q2rhjvjWcV/beredskap/rodt-fareniva) før du handler.
