# LPS-kurs

## Innhold

Egensikkerhet, pasientundersøkelse, HLR, skuddskader, knivstikking, brudd, hodeskader, brannskader, trafikkulykker, pasienttransport og samband.

**Serverens XABCDE:** X = Egensikkerhet, A = Airway, B = Breathing, C = Circulation, D = Disability, E = Exposure. Dette er et RP-oppsett.

Bruk `/meg` for å beskrive relevante handlinger i RP.

## Praktisk prøve

Fem scenarioer: **trafikkulykke, skuddskade, bevisstløs person, knivstikking og fall fra høyde**. Instruktør dokumenterer resultatet i intern kurslogg.
